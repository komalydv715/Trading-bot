# Python CLI Trading Bot

A command-line trading bot built using Python that simulates stock/crypto trading operations including buying, selling, portfolio tracking, and transaction management.

## Features
- Buy and Sell Assets
- Portfolio Tracking
- Transaction History
- Balance Management
- Real-time/Mock Market Data

## Tech Stack
- Python
- Requests
- JSON
- CLI
